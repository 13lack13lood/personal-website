# Personal Website

My personal website where you can find more about me. Made with Next.js and React, styled with plain CSS (Gambetta and General Sans from Fontshare). Deployed using Vercel.

- `src/app/page.tsx`: the page content (landing, about, experience, projects, contact)
- `src/app/globals.css`: all styles, dark by default with a light theme
- `public/quiet.js`: theme toggle, section highlighting in the nav, collapsible experience details, and the animated project charts
- `public/resume.pdf`, `public/harry.jpg`: resume and portrait

Run locally with `npm run dev`.
